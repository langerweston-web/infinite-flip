# Infinite Flip

Coin-flip idle game with shop upgrades and a local scoreboard.

## Play

- **Online:** https://langerweston-web.github.io/infinite-flip/
- **Offline:** open `docs/index.html` (or `public/index.html`) in your browser — no server needed.

## Scoreboard

Open **SCOREBOARD** in the header (near STATS). Set your name and submit (or keep playing — it auto-saves when your best streak improves). Scores stay in this browser via `localStorage`.

## Shop caps

- **Luck** — max at 75% (level 5)
- **Speed** — max at 500ms flip floor
- **Crit** — max at 100%
- **Auto flip** — max at 5
- **Extra coins** — shown as gold pips under the main coin
