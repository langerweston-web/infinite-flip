# Infinite Flip (Desktop)

Windows desktop app built with Electron.

## Play online

https://langerweston-web.github.io/infinite-flip/

## Run / build on Windows

Needs [Node.js](https://nodejs.org) installed once.

```bat
npm install
npm start
```

Build a portable `.exe` (no installer):

```bat
npm run dist
```

The app lands in the `dist` folder as **Infinite Flip.exe** (portable). Double-click to play — no browser, no server.
